# Training evidence (baseline)

No fine-tuning or data-generation has been performed in this starter baseline.
The inference system uses an eligible pre-trained checkpoint, local prompts, SQL execution,
and no trained adapters. Team must fill in the exact checkpoint/revision/license/source and
include required evaluation, verification and training artifacts if they later train any model.

DO NOT copy public or private test data into training. If you train, include configs,
training scripts, prompt templates, allowed training/validation data, run logs,
checkpoints, and a SHA-256 data manifest. See Docker Guide Section 8.
